# Código Garra - API Backend
## Descripción del Proyecto
Código Garra es una API REST diseñada para solucionar la desconexión crítica durante emergencias veterinarias nocturnas o en feriados en Manta.
Conecta a dueños de mascotas en situaciones de urgencia con las clínicas veterinarias que disponen del equipo específico requerido libre en ese exacto minuto, gestionando la disponibilidad mediante estados dinámicos y ventanas de tiempo.

## Stack Tecnológico
* **Lenguaje:** Go (1.22+)
* **Router:** Chi
* **ORM:** GORM
* **Autenticación:** JWT (golang-jwt)
* **Testing:** Testify (con mocks)
* **Base de Datos:** SQLite (Desarrollo) / PostgreSQL (Producción)
* **Infraestructura:** Docker & Docker Compose
